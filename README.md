## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/engineersayyamshahid/python-data-science-journey.git
```

### 2. Navigate to the Project

```bash
cd python-data-science-journey
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install numpy pandas matplotlib seaborn plotly jupyter openpyxl
```

### 6. Launch Jupyter Notebook

```bash
jupyter notebook
```

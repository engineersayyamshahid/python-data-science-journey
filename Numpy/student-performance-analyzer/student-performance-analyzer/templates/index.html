How the NumPy engine works

The backend converts the saved student marks into a two-dimensional NumPy array. It uses axis-based calculations for subject and student averages, boolean masks for pass/fail analysis, and sorting functions to generate student rankings.

np.mean(matrix, axis=0)np.all(matrix >= 50, axis=1)np.argsort(averages)np.std(matrix)
